# Overview

This is a personal knowledge base kept as plain Markdown in the
**Open Knowledge Format (OKF)**. Each page is one *concept* — a source, an idea,
a person, a project, a note — and pages link to each other to form a graph you
can browse here or in Obsidian.

It is maintained mostly by coding agents, which follow the rules in `CLAUDE.md`
at the repository root.

# Domains

_No domains yet._ As the wiki grows, each subject gets a folder under `wiki/`
with its own `index.md`, listed here and in the [root index](index.md).
